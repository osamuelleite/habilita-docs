# Modelo de Registro de Entrevista

> Título do arquivo copiado: `# Entrevista E0X — [perfil genérico, ex.: Gerente de SST, indústria]`

> Copie este arquivo para `entrevista-E01.md` (ou E02) e preencha. **Não** inclua nome, CPF, telefone, e-mail nem nome da empresa.

| Campo | Valor |
|---|---|
| Código | E0X |
| Data | DD/MM/AAAA |
| Perfil | Função genérica, setor, porte (ex.: ~300 terceirizados/mês) |
| Canal | Presencial / vídeo / telefone |
| Entrevistador / anotador | Papéis na equipe (ex.: PO / QA) |
| Consentimento verbal | Sim / Não |
| Gravação | Não houve / Autorizada e apagada em DD/MM |
